This Tesseract LSTM model for printed Hebrew square script was fine-tuned from
Google's tessdata_best Hebrew model and further trained by the upstream project.
The upstream project identifies the model as licensed under the Apache License,
Version 2.0. A copy of that license is distributed alongside this notice.

The model is an optional local fallback for weak OCR results. It is bundled into
the Windows application and is not downloaded by users or invoked through a
remote service. The recipe application does not include the upstream Sefaria
word lists or its domain-specific spelling corrector.
