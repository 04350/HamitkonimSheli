# ספריית המתכונים שלי

תוכנה שולחנית מלאה בעברית ל-Windows 10 ו-Windows 11. קובץ ההפעלה נבנה כקובץ EXE יחיד; במחשב המשתמש לא נדרשים Python, התקנת ספריות או חיבור לאינטרנט.

## מה התוכנה עושה
- מייבאת קבצים בודדים, תיקיות שלמות ותתי-תיקיות.
- מאפשרת לגרור ולשחרר קבצים ותיקיות לחלון.
- מזהה כותרת ממסמכים ושומרת עותק מקומי בשם הכותרת; כשאין כותרת, משתמשת בשם הקובץ או בכותרת שבתמונת המקור.
- מחפשת קודם בשם המתכון או הקובץ, ואחר כך בתוכן המסמך. החיפוש מנרמל ניקוד עברי וסימני פיסוק ותומך בהתאמה גמישה.
- מציגה תמונות בתצוגה מקדימה, ופותחת כל קובץ בתוכנת ברירת המחדל של Windows.
- מאפשרת שינוי שם, הסרה, פתיחת תיקיית הנתונים ויצירת גיבוי ZIP.
- שומרת את הנתונים ב-%LOCALAPPDATA%\\ספריית המתכונים שלי, בנפרד מקובץ ההפעלה, כדי שעדכון התוכנה לא ימחק אותם.

## סוגי קבצים
- מסמכים: PDF עם שכבת טקסט, DOCX, ODT, RTF, TXT, Markdown, HTML, CSV ו-TSV.
- גיליונות ומצגות: XLSX, XLSM ו-PPTX.
- ספרים דיגיטליים: EPUB.
- תמונות: PNG, JPG, JPEG, GIF, BMP, TIFF ו-WEBP.
- ניתן להוסיף גם סוגי קבצים נוספים. קבצים שאינם נתמכים לקריאת תוכן יישמרו בספרייה ויהיו ניתנים לחיפוש לפי שם הקובץ ולפתיחה בתוכנת Windows המתאימה.

ב-PDF שהוא סריקה בלבד אין שכבת טקסט ולכן החיפוש בתוכן אינו זמין; התוכנה אינה משתמשת ב-OCR. תמונות נשמרות ומוצגות בתצוגה מקדימה, אך לא מתבצע זיהוי טקסט מתוך תמונה.

## עברית ופרטיות
כל הממשק, הכותרות, ההודעות, ההגדרות והחיפוש מוצגים בעברית. התוכנה פועלת מקומית בלבד: אין שירות ענן, חשבון משתמש, שליחת מידע, מדידה או מעקב. קובצי המקור אינם נמחקים; התוכנה שומרת עותקים בספרייה המקומית.

## גיבוי
אפשר ליצור מתוך התוכנה קובץ ZIP המכיל את מסד הנתונים ואת הקבצים שיובאו. מומלץ לשמור גיבוי נוסף בכונן חיצוני.

## בנייה ובדיקות
תהליך הבנייה נמצא ב-.github/workflows/build-windows.yml. הוא מתקין את הספריות, מריץ בדיקות קוד, יוצר קובץ EXE יחיד, בודק שקובץ ההפעלה נוצר ונשאר פתוח בבדיקת הפעלה, ושומר אותו כקובץ להורדה למשך 30 יום.
