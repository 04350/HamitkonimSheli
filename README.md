## מה חדש בגרסה 2.0.0?

גרסה 2.0.0 מרכזת את שיפורי הביצועים והיציבות שנוספו בפרויקט:

- **גלריה יעילה יותר:** מטמון תמונות חכם שמותאם לגודל הספרייה, עם תקציב זיכרון מוגבל ופינוי תמונות שלא נעשה בהן שימוש.
- **בדיקת ספרייה גדולה:** בדיקה אוטומטית של מסד נתונים עם 3,000 פריטים, כולל שליפת תגיות מרוכזת.
- **OCR משופר:** התאמת עיבוד התמונה, זיהוי סריקות מסובבות ושיפור מודל הזיהוי בעברית.
- **עבודה חלקה יותר:** ייבוא וחילוץ רכיבי Office ברקע, עם הצגת התקדמות.
- **ממשק אחיד:** מסכי העבודה המרכזיים נפתחים בתוך החלון הראשי, עם חלונית קריאה שניתנת לשינוי רוחב.
- **בלי תוספת מיותרת:** לא נוספו ספריות Python חדשות עבור שיפורי הגלריה והביצועים.

## פרטיות ועבודה מקומית

- כל המתכונים, המסמכים וההגדרות נשמרים במחשב שלך.
- אין צורך בחשבון, בהרשמה או בחיבור לאינטרנט בזמן השימוש.
- התוכנה אינה שולחת את הקבצים לשירות ענן.
- הנתונים נשמרים בנפרד מקובץ ההפעלה, כך שעדכון התוכנה אינו אמור למחוק את הספרייה.

## התקנה והפעלה

1. מורידים את קובץ ה־ZIP ומחלצים את התיקייה.
2. משאירים את קובץ ההפעלה ואת `LibreOffice.zip` באותה תיקייה.
3. מפעילים את קובץ ה־EXE.

**אין צורך לחלץ את `LibreOffice.zip` ידנית.** התוכנה פורסת את רכיבי Office בעצמה בפעם הראשונה שבה נדרשת תצוגת Office או יצירת PDF.

- מיועדת ל־Windows 10 ו־Windows 11.
- אין צורך להתקין Python או ספריות נוספות.
- גודל חבילת ההורדה: כ־416.6MB.
