# ספריית המתכונים שלי

אפליקציית Windows בעברית לניהול ספרייה אישית של מתכונים, מסמכים, תמונות וקבצים דיגיטליים — במקום אחד, עם חיפוש בתוכן הקבצים ותצוגה בתוך התוכנה.

## מה אפשר לעשות?

- **ייבוא קבצים לספרייה** – הוספת קבצים מהמחשב, ושמירת עותק שלהם בתיקיית הספרייה המקומית.
- **חיפוש מהיר** – חיפוש לפי שם הקובץ וגם לפי טקסט שחולץ מתוכנו.
- **תצוגה מקדימה בתוך התוכנה** – צפייה במסמכים ובקבצים נתמכים בלי לפתוח בכל פעם תוכנה חיצונית.
- **ניהול פריטים** – שינוי שמות והסרת פריטים מהספרייה.
- **זיהוי טקסט בתמונות ובמסמכים סרוקים (OCR)** – כאשר רכיבי הזיהוי המתאימים זמינים בחבילה.
- **עבודה בעברית** – ממשק המשתמש מיועד לעבודה בעברית.

## סוגי קבצים נתמכים

| סוג | פורמטים |
|---|---|
| תמונות | PNG, JPG, JPEG, GIF, BMP, TIF, TIFF, WEBP |
| מסמכים | PDF, HTML, HTM, TXT, MD, CSV, TSV, LOG |
| Word | DOC, DOCX, DOCM, ODT, RTF |
| Excel | XLS, XLSX, XLSM, ODS |
| מצגות | PPT, PPTX, PPTM, ODP |
| ספרים דיגיטליים | EPUB, MOBI, FB2 |

התמיכה בתצוגה ובחילוץ הטקסט משתנה לפי הפורמט. מסמכי Office מוצגים באמצעות המרה שקטה ל-PDF בעזרת LibreOffice הכלול בחבילת Windows המלאה. פורמטים ישנים או מיוחדים עשויים להציג תצוגה חלקית או לדרוש רכיב מתאים.

## התקנה והפעלה ב-Windows

1. פתחו את [דף ההרצות של GitHub Actions](https://github.com/04350/HamitkonimSheli/actions).
2. בחרו בהרצה המוצלחת האחרונה.
3. באזור **Artifacts** הורידו את החבילה **ספריית-המתכונים-שלי-Windows-כולל-Office**.
4. חלצו את קובץ ה-ZIP לתיקייה במחשב.
5. הפעילו את קובץ ה-EXE שבתיקייה שחולצה.

**חשוב:** בחבילה המלאה יש להשאיר את קובץ ה-EXE ואת תיקיית `LibreOffice` יחד באותה סביבת תיקיות. אין להעתיק את קובץ ה-EXE לבדו למקום אחר, אחרת תצוגת מסמכי Office עלולה שלא לפעול.

אפשר גם להוריד את קובץ ה-EXE הבסיסי, אך הוא אינו כולל את כל רכיבי התצוגה של חבילת Office.

## היכן נשמרים הקבצים?

הספרייה נשמרת מקומית במחשב, תחת תיקיית המשתמש:

```
%LOCALAPPDATA%\\ספריית המתכונים שלי
```

בתוכה נמצאים מסד הנתונים של הספרייה ותיקיית **הקבצים שלי** שבה נשמרים הקבצים שיובאו.

הסרת פריט מתוך התוכנה מוחקת את העותק שנשמר בספרייה. מומלץ לשמור עותק גיבוי של התיקייה כולה, במיוחד של הקבצים ושל מסד הנתונים.

## פרטיות

האפליקציה מיועדת לעבודה מקומית. לפי מימוש התוכנה, הקבצים ומסד הנתונים נשמרים במחשב ואין שליחה יזומה של תוכן הקבצים לשרת חיצוני.

## מגבלות שימוש

- גודל קובץ מרבי לייבוא: **250MB**.
- תצוגת מסמכי Office דורשת את תיקיית LibreOffice המצורפת לחבילה המלאה.
- איכות חילוץ הטקסט תלויה בסוג הקובץ, במבנה המסמך ובאיכות הסריקה.
- מומלץ לגבות את תיקיית הנתונים באופן קבוע.

## פיתוח והרצה מקוד המקור

הפרויקט כתוב ב-Python ומשתמש בממשק Tkinter. רכיבים נוספים משמשים לקריאת מסמכים, תמונות, PDF ו-OCR.

להרצת הבדיקות:

```bash
python -m unittest discover -s tests -v
```
