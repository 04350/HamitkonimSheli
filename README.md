# ספריית המתכונים שלי

אפליקציית Windows בעברית לניהול ספרייה אישית של מתכונים, מסמכים, תמונות וקבצים דיגיטליים — במקום אחד. מסך הספרייה נשאר מרכז התוכנה: חיפוש, סינון, מיון, תצוגה מקדימה וניהול הקבצים. כלי הבישול וההדפסה נמצאים בחלון נפרד בשם **מרכז המתכונים**, כדי לא להעמיס על המסך הראשי.

## חדש בגרסה 1.5.0

- **מרכז מתכונים בלשוניות** – חלון נפרד עם הדפסה וחוברות, רשימת קניות, תכנון שבועי ומצב בישול.
- **הדפסת מתכון או חוברת PDF** – בחירה של מתכון אחד או מספר מתכונים, הוספת כותרת לחוברת, אפשרות לכלול הערות, ויצירת PDF בעברית ובכיווניות ימין־לשמאל. כל מתכון מתחיל בעמוד חדש.
- **פתיחה מהירה להדפסה** – כפתור הדפסה זמין גם כאשר מתכון נבחר בתצוגה המקדימה של הספרייה.
- **רשימת קניות** – איסוף מצרכים מכמה מתכונים, איחוד שורות זהות ושמירה לקובץ טקסט. כמויות ויחידות שונות נשארות נפרדות כדי למנוע חיבור שגוי.
- **תכנון תפריט שבועי** – בחירת מתכונים לארוחות בוקר, צהריים וערב לכל ימות השבוע; התכנון נשמר במחשב.
- **מצב בישול** – הצגת הוראות ההכנה של מתכון בשלבים, עם מעבר קדימה ואחורה.
- **חיפוש לפי מצרכים והוראות** – החיפוש הראשי מוצא כעת גם מילים מתוך שדות המצרכים, הוראות ההכנה וההערות.
- **ללא שינוי במבנה הספרייה** – מסך הרשימה/גלריה, החיפוש, הסינון, התצוגה המקדימה והניהול נשארים המסך המרכזי.

### תכונות מגרסאות קודמות

- תצוגת מתכון מקצועית: קטגוריה, מצרכים, הוראות, זמני הכנה ובישול, מספר מנות והערות.
- זיהוי מצרכים מתוך הטקסט וחישוב כמויות לפי מספר מנות.
- תצוגת גלריה ורשימה עם שמירת בחירה.
- מועדפים, אוספים אישיים ותגיות.
- חיפוש וסינון לפי סוג קובץ, תאריכים, קטגוריה ותגיות; מיון לפי שם, תאריך, סוג, גודל ותאריך צפייה אחרון.
- תצוגה מקדימה ל-PDF, מסמכי Office, ספרים דיגיטליים, תמונות וקובצי טקסט.
- איתור פריטים דומים, סל מחזור ושחזור.
- גיבוי ושחזור מלאים, וכן גיבוי אוטומטי מתוזמן.
- קיצורי מקלדת וסרגל התקדמות בזמן ייבוא קבצים.

## מה אפשר לעשות?

- **ייבוא קבצים לספרייה** – הוספת קבצים מהמחשב ושמירת עותק שלהם בתיקיית הספרייה המקומית.
- **חיפוש מהיר** – חיפוש לפי שם הקובץ, תוכנו, מצרכי המתכון, הוראות ההכנה והערות.
- **תצוגה מקדימה בתוך התוכנה** – צפייה במסמכים ובקבצים נתמכים בלי לפתוח בכל פעם תוכנה חיצונית.
- **ניהול פריטים** – שינוי שמות, סל מחזור, מועדפים, אוספים אישיים ותגיות.
- **זיהוי טקסט בתמונות ובמסמכים סרוקים (OCR)** – כאשר רכיבי הזיהוי המתאימים זמינים בחבילה.
- **עבודה בעברית** – ממשק המשתמש מיועד לעבודה בעברית.

## סוגי קבצים נתמכים

| סוג | פורמטים |
|---|---|
| תמונות | PNG, JPG, JPEG, GIF, BMP, TIF, TIFF, WEBP |
| מסמכים | PDF, HTML, HTM, TXT, MD, CSV, TSV, LOG |
| Word | DOC, DOCX, DOCM, ODT, RTF |
| Excel | XLS, XLSX, XLSM, ODS |
| מצגות | PPT, PPTX, PPTM, ODP |
| ספרים דיגיטליים | EPUB, MOBI, FB2 |

התמיכה בתצוגה ובחילוץ הטקסט משתנה לפי הפורמט. מסמכי Office וחוברות PDF נוצרים באמצעות LibreOffice הכלול בחבילת Windows המלאה. פורמטים ישנים או מיוחדים עשויים להציג תצוגה חלקית או לדרוש רכיב מתאים.

## התקנה והפעלה ב-Windows

1. הורידו את [חבילת Windows המלאה – הורדה ישירה](https://github.com/04350/HamitkonimSheli/releases/latest/download/recipe-library-windows-office.zip).
2. חלצו את קובץ ה-ZIP לתיקייה במחשב.
3. הפעילו את קובץ ה-EXE שבתיקייה שחולצה.

**חשוב:** בחבילה המלאה יש להשאיר את קובץ ה-EXE ואת תיקיית `LibreOffice` יחד באותה סביבת תיקיות. אין להעתיק את קובץ ה-EXE לבדו למקום אחר, אחרת תצוגת מסמכי Office ויצירת PDF עלולות שלא לפעול.

אפשר גם להוריד את קובץ ה-EXE הבסיסי מתוך [עמוד הגרסה](https://github.com/04350/HamitkonimSheli/releases/latest), אך הוא אינו כולל את כל רכיבי התצוגה של חבילת Office.

## היכן נשמרים הקבצים?

הספרייה נשמרת מקומית במחשב, תחת תיקיית המשתמש:

```
%LOCALAPPDATA%\\ספריית המתכונים שלי
```

בתוכה נמצאים מסד הנתונים של הספרייה ותיקיית **הקבצים שלי** שבה נשמרים הקבצים שיובאו. התכנון השבועי וההעדפות נשמרים במסד הנתונים המקומי.

## פרטיות

האפליקציה מיועדת לעבודה מקומית. הקבצים ומסד הנתונים נשמרים במחשב ואין שליחה יזומה של תוכן הקבצים לשרת חיצוני.

## מגבלות שימוש

- גודל קובץ מרבי לייבוא: **250MB**.
- תצוגת מסמכי Office ויצירת חוברות PDF דורשות את תיקיית LibreOffice המצורפת לחבילה המלאה.
- איכות חילוץ הטקסט תלויה בסוג הקובץ, במבנה המסמך ובאיכות הסריקה.
- מומלץ לגבות את תיקיית הנתונים באופן קבוע.

## פיתוח והרצה מקוד המקור

הפרויקט כתוב ב-Python ומשתמש בממשק Tkinter. רכיבים נוספים משמשים לקריאת מסמכים, תמונות, PDF ו-OCR.

להרצת הבדיקות:

```bash
python -m unittest discover -s tests -v
```
